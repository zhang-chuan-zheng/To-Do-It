# Quotes

`philosophy_quotes.json` 是 To Do It 的离线哲学名言库，当前 `schemaVersion` 为 `1`，共收录 1000 条。数据以《周易》《论语》《孟子》《大学》《中庸》《礼记》《尚书》《诗经》《孝经》等公有领域原典短句为主体，并包含毛泽东、黑格尔、马克思、恩格斯和尼采著作的少量思想摘意。

每条记录的稳定字段为 `id`、`text`、`author`、`source`、`verified`；扩展字段 `sourceLocator` 记录篇章位置，`textType` 区分 `原文` 与 `意译`，`tags` 用于未来按主题筛选。`意译` 是编辑整理后的非逐字引文，界面或导出功能不得把它标成原文直引。

维护规则：

- 新增记录必须具有唯一 ID、非空作者、明确作品出处和可复核的篇章位置。
- 不录入来源不明的网络语录、常见误传或默认窗口下必须缩至正常字号 50% 以下才能显示的长段落。
- 原文优先选用公有领域或兼容许可的底本；现代作者优先采用简短思想摘意，避免大段复制受保护文本。
- 修改条目后同步更新顶层 `count`，并检查 ID 与正文均无重复。
- 顶层 `sources` 记录本批数据使用的底本、核对站点与许可说明；新增底本时必须同时补充该清单。
