# Updater

独立 `ToDoItMigrator` 只链接 Qt Core、基础设施 CSV 仓储和更新核心，不链接主界面。安装或更新时，它读取 `release-manifest.json`，锁定数据目录，检测 `event.csv` 架构，创建永久迁移备份，并用正式仓储执行字段、UUID、父子图、时间和附件完整性校验；成功后原子写入安装状态并追加不含事项正文的 JSONL 更新历史。

0.1.0 是首个发布架构；当前发布目标 0.2.0 继续使用 `eventSchema=1`，因此当前可执行路径是“缺失文件初始化”或“v1 备份后只读验证”，不会无故重写用户字段。未知无版本格式、较新格式或缺少连续迁移步骤时会中止且不修改原文件。

每份未来发布清单必须保留它支持迁移的全部旧 `eventSchemas` 定义，并为每个相邻版本声明 `eventMigrations`。通用迁移器按大小写敏感的稳定字段名复制同名数据；目标新增字段使用目标架构中声明的字符串缺省值；目标删除字段只有在对应迁移的 `removedFields` 中显式列出后才允许丢弃。字段意外改名会被当作未授权删除而阻止更新，禁止根据相似列名猜测用户数据。迁移候选文件通过当前正式 CSV 仓储完整校验后才原子替换原文件；安装状态写入失败时会从迁移备份恢复。
